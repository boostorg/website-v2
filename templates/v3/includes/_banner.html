{% comment %} V3 Banner — amber by default, with optional icon, auto-fade, action and close (X). Either dismiss_id or dismiss_key renders a CSS-only close button that works without JS; dismiss_key additionally persists the dismissal across pages in sessionStorage via @alpinejs/persist. Without either, the Alpine close button is hidden when JS is off, and the banner simply stays. Variables: banner_message (required) — HTML message body; passed through |safe. A \n in the text breaks the line on mobile only (banner.css) — use it to split a two-sentence message; it is a space elsewhere. icon_name (optional) — leading icon name. See includes/icon.html. fade_time (optional) — milliseconds after which the banner auto-fades. See animations.css. dismiss_key (optional) — key scoping the dismissed state in sessionStorage, and the close checkbox id. Omit for one-shot messages: a persisted key would also suppress the next message using it. variant (optional) — "success" or "error"; adds .banner--. Default is amber. role (optional) — ARIA role, default "alert". Use "status" to announce politely, or "region" (with aria_label) for a notice already on the page at load. aria_label (optional) — accessible name, required when role="region". action_url (optional) — with action_label, renders a POST form (e.g. "Cancel deletion"). action_label (optional) — submit button text for action_url. dismiss_id (optional) — page-unique value scoping the close checkbox, for banners with no dismiss_key. Use it for banners that never fade. Usage: {% include "v3/includes/_banner.html" with banner_message="Heads up!" icon_name="alert" dismiss_key="my-banner" %} {% endcomment %}
