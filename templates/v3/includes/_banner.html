{% comment %} V3 Banner — amber alert with optional icon, optional auto-fade, and a built-in close (X) button. Dismissal persists in sessionStorage under `banner-{{ dismiss_key }}` (via @alpinejs/persist) when dismiss_key is set; otherwise it is in-memory only. When JS is disabled, the banner is always visible and the close button does not render. Variables: banner_message (required) — HTML message body; passed through |safe. icon_name (optional) — leading icon name. See includes/icon.html. fade_time (optional) — milliseconds after which the banner auto-fades. See animations.css. dismiss_key (optional) — unique key scoping the dismissed-state in sessionStorage. Usage: {% include "v3/includes/_banner.html" with banner_message="Heads up!" icon_name="alert" dismiss_key="my-banner" %} {% endcomment %}
