{% comment %} V3 flash messages — renders each queued Django message as a v3 banner. Replaces partials/messages.html on the v3 path (see base.html's messages block). Sits in base.html's messages slot, directly under the navbar. The slot's header reservation and inset live in banner.css (body.v3 .w-full:has(> .banner-stack)), keyed off .banner-stack, so nothing renders — and no space is reserved — when there are no messages. Only the most recent message is shown. The loop still runs over the whole queue so every message is marked read and none leaks onto the next page. Success and info fade out after 6s; warning and error stay until dismissed, so they carry a dismiss_id, which gives them a CSS-only close button that works without JS. Variables: messages (required) — from django.contrib.messages, via the context processor. {% endcomment %} {% if messages %}
{% for message in messages %} {% if forloop.last %} {% if message.level_tag == "success" %} {% include "v3/includes/_banner.html" with banner_message=message icon_name="checkbox" variant="success" fade_time=6000 %} {% elif message.level_tag == "error" %} {% include "v3/includes/_banner.html" with banner_message=message icon_name="warning-box" variant="error" dismiss_id=forloop.counter %} {% elif message.level_tag == "warning" %} {% include "v3/includes/_banner.html" with banner_message=message icon_name="alert" dismiss_id=forloop.counter %} {% else %} {% include "v3/includes/_banner.html" with banner_message=message icon_name="checkbox" fade_time=6000 %} {% endif %} {% endif %} {% endfor %}
