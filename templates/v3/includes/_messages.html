{% comment %} V3 flash messages — renders each queued Django message as a v3 banner. Replaces partials/messages.html on the v3 path (see base.html's messages block). Sits in base.html's messages slot, directly under the navbar. The slot's header reservation and inset live in banner.css (body.v3 .w-full:has(> .banner-stack)), keyed off .banner-stack, so nothing renders — and no space is reserved — when there are no messages. Standing notices first (scheduled deletion, then the version alert), flash messages after them, newest last. Everything here overlays the page rather than taking flow space, so nothing shifts when a banner appears or is dismissed — and the version alert stacks with the rest instead of overlapping it, which is what happened while it lived inside the hero. Success and info fade out after 6s; warning, error and the deletion banner stay until dismissed, so they carry a dismiss_id, which gives them a CSS-only close button that works without JS.
